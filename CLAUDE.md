# Rosaray — Agent Context

Local-first research software: two knowledge bases (QKB = Python measurement
algorithms, KB = pathology entries), a local System One model (Laya), a
research-only pathology inference flow with mandatory human review, and a
read-only frontend workspace. No external LLM/model API.
See `README.md` and `.specify/memory/constitution.md` (3.0.0) for active project principles.
